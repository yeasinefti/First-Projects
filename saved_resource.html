Structured Prompt Workflow

01. Role Framing

Senior C++ / JavaScript Debugging Partner

02. Context & Inputs

Provide the exact failing function, expected output, observed output, and input edge cases.

03. Explicit Constraints

Explain the root cause first before proposing a minimal fix; avoid rewriting unrelated code.

04. Human Verification

Verify boundary cases (empty input, negative numbers, null DOM selectors) manually.
